# SportsTurf Portal

A React-based single-page application for discovering and reserving sports arenas across Thane, Kalyan, and Dombivli.

## Features

- Dynamic arena catalog with pricing and location details
- Interactive booking modal with client-side state handling
- Direct form interaction using React hooks
- Responsive navigation and clean component architecture

## Tech Stack

- Frontend: React.js
- Build Tool: Vite
- Routing: React Router DOM
- Styling: Plain CSS
